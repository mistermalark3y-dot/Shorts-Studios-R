# Shorts Studio

A starter dashboard for managing multiple faceless YouTube Shorts channels.

## Run it on Windows

1. Install Node.js LTS and Visual Studio Code.
2. Extract this ZIP.
3. Open the folder that contains `package.json` in VS Code.
4. Open **Terminal → New Terminal**.
5. Run:

```bash
npm install
npm run dev
```

6. Open http://localhost:3000

## Current milestone

This version provides a working Next.js dashboard shell with Overview, Channels, Content and Settings pages. The YouTube button is intentionally not connected yet; Google OAuth is the next milestone.

## Environment variables

Copy `.env.example` to `.env.local` when integrations are added.
